  <Card title="Version bumping" icon="rocket">

  </Card>
  <Card title="Git & GitHub / GitLab" icon="seti:git">
    Commit, tag, push, and open a release on [GitHub](/release-it/guides/publishing/github-releases/) or
    [GitLab](/release-it/guides/publishing/gitlab-releases/) — all in one command.
  </Card>
  <Card title="Changelogs & pre-releases" icon="pencil">

    [`alpha` / `beta` / `rc`](/release-it/guides/core-workflow/pre-releases/) versions.
  </Card>
  <Card title="npm publishing" icon="seti:npm">
    [Publish](/release-it/guides/publishing/npm/) to any registry — with support for OTP, WebAuthn, staged
    publishing and OIDC Trusted Publishing.
  </Card>
  <Card title="Runs anywhere" icon="approve-check">
    Interactive locally, non-interactive in [GitHub Actions, GitLab CI, Travis, CircleCI](/release-it/guides/ci/environments/),
    or your own shell scripts.
  </Card>
  <Card title="Extendable" icon="puzzle">
    A [plugin API](/release-it/reference/plugin-api/) lets you hook into every step — bring your
    own version file, notifier, or release strategy.
